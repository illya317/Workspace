# 业务编码规则

root 管理员在 `/settings/admin` 的“编码管理”维护模板和编码绑定。配置只影响之后的新建记录和尚未入库的导入；已经入库的编号不会追溯重算。

## 模板维护

页面采用左侧模板列表、右侧详情的主从分栏，不再拆分独立的“编码维护”视图。系统模板只读，可“复制为自定义模板”；自定义模板可编辑和删除。点击 `+` 会在右侧打开空白 block，不弹窗，也不要求先选基础结构。

每个模板都使用相同编辑方式：

1. 新增一条或多条规则分支。
2. 为分支选择可选的适用条件。
3. 依次添加固定文本、业务字段、日期、完整时间或流水号。
4. 流水号单独设置起始值、可选结束值和流水作用域。
5. 每条条件分支显示自己的适用条件和完整示例，再通过模板总样例检查最终结果。

规则分支从上到下匹配，第一条满足全部条件的规则生效。页面不开放脚本；只能使用后端登记的字段、条件和安全转换。

当前八个系统 baseline 都能通过同一个 `+` 编辑器从空白重建：通用流水、年度流水、日期流水、时间流水、组织分层、组织岗位、年度项目和财务资产。

## 关联编码对象

每个模板详情顶部显示“关联编码对象”，采用与 HR 直属岗位一致的两列关联卡片。每张卡片只显示编号样例和编码对象名称，不展开重复配置字段。

- 编码对象只读，由后端 registry 决定；当前页面不能新增“哪个字段需要编码”。
- 右上角 `+` 只列出与当前模板兼容且尚未关联的后端编码对象。
- 点击现有卡片可以把编码对象改绑到另一兼容模板。
- 卡片编号由当前业务配置和模板自动生成，不提供单独的样例编辑框。
- 新增和改绑通过区块内保存立即持久化，不设置额外的保存或撤销按钮。

以后新增编码对象时，开发者必须先在 `packages/platform/business-code-registry.ts` 登记对象键、Owner、默认模板和实现入口；它会自动出现在所用模板的“关联编码对象”和生成文档中，不需要再修改前端选项。

## 当前默认结果

| 对象 | 当前结构 | 示例 |
|---|---|---|
| 员工 | 流水 | `00001` |
| 管理组织 | 组织简称 + 分层段 | `FUN-001`、`FUN-100`、`FUN-101` |
| 岗位 | 固定文本 + 直属组织编码 + 流水 | `GW-FUN-001-01` |
| 客户 | 固定文本 + 流水 | `CUS-00001` |
| 供应商 | 固定文本 + 流水 | `SUP-00001` |
| 项目 | 项目标识或部门编码 + 年度 + 分域流水 | `EX-26-001` |
| 财务资产 | 公司 + 资产分类 + 账期年度 + 5 位流水 | `02-FA-ELECTRONIC-2026-00001` |

组织分层和年度项目使用条件分支表达，不再拥有单独的编辑页面。组织简称、直属组织编码、公司编码、资产分类编码等仍由对应业务主数据提供；模板只组合这些值。

## 财务资产编号

- 资产流水按公司编码、账期年度和资产分类编码独立计数。
- 流水固定 5 位，超过 `99999`、缺字段、没有生效规则或作用域不完整时拒绝写入。
- 预览只显示候选号，不占号；最终保存仍在创建资产卡片的同一数据库事务内原子占号。
- 手工创建使用 `manual:<UUID>`，导入使用 `import:<companyCode>:<sourceKey>` 作为分配幂等键。
- Excel 原资产编号只作为来源证据保存，不替代 canonical 资产编号；实物标签号保持独立。

## 日期格式

日期支持 `YYYY`、`YY`、`MMM`、`MM`、`DD`，完整时间另支持 `HH`、`mm`、`ss`。例如：

- `YYMM` → `2607`
- `YYMMM` → `26JUL`
- `YYYY-MM-DD` → `2026-07-29`
- `YYMMDDHHmmss` → `260729150806`

格式大小写错误、重复单位或缺少必要日期值时禁止保存。
